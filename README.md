# 아마란스 근무시간 계산기

아마란스 그룹웨어(`gwa.soomgo.com`)에서 이번 달 출결 내역을 불러오거나 `detailGrid_excel_*.xlsx` 파일을 읽어 월별 근무시간과 부족/초과 시간을 계산하고, 결과를 엑셀로 저장하는 Windows/macOS 데스크탑 앱입니다. 계산은 기기에서만 수행됩니다.

## 다운로드 및 사용

1. [Releases](https://github.com/bez-soomgo/amaranth-attendance/releases)에서 운영체제에 맞는 설치 파일을 내려받습니다.
2. 앱을 실행하면 그룹웨어에서 이번 달 출결을 바로 불러옵니다. 로그인이 필요하면 앱 안에 그룹웨어 로그인 창이 열리고, 로그인하면 창이 닫히며 계산 결과가 표시됩니다. 사번은 로그인한 세션에서 읽으므로 본인 기록만 조회합니다. `엑셀 파일 열기`를 누르거나 `detailGrid_excel_*.xlsx` 파일을 앱으로 끌어다 놓아 엑셀로 계산할 수도 있습니다.
3. 처음 보는 근태항목은 처리 규칙을 선택합니다. 선택한 규칙은 기기에 저장되며 `규칙 설정`에서 삭제할 수 있습니다.
4. 일별 계산과 월간 요약을 확인하고 `엑셀로 저장`을 누릅니다. `오늘 퇴근 목표`는 그룹웨어 메인 화면의 오늘 출근 기록으로 자동 계산하며, 오늘 근태(일반 근무 / 4시간 가산)를 바꾸면 다시 계산합니다. 오늘 출근 기록이 없으면 출근 시각을 직접 입력합니다.

## 계산 규칙

1. **대상 행**: `출결구분 == 정상근무`인 행만 처리합니다. 현지 오늘보다 뒤인 날짜는 제외합니다.
2. **근태항목 분류**: 항목의 모든 공백을 제거해 분류합니다. 빈 항목과 `야간근무`는 일반 근무, `연차`는 8시간 인정, `오전반차`·`오후반차`·`생일휴가`·`건강검진`·`단축*`은 4시간 가산, `업무 중 휴게`는 근태신청 시간을 추가 차감합니다. 그 외에는 저장된 사용자 지정 규칙을 적용합니다. 규칙이 없는 항목이 하나라도 있으면 계산 결과 대신 처리 방식을 먼저 묻습니다.
3. **출퇴근 기록**: 출근·퇴근이 모두 비었거나 규칙이 8시간 인정이면 8시간을 인정하고 근무일에 포함합니다. 한쪽만 비어 있으면 계산에서 제외합니다. 오늘 출근만 기록된 행은 `오늘 근무 중 — 계산 제외`, 그 외는 `출퇴근 기록 불완전 — 계산 제외`로 표시합니다.
4. **사용자 지정 제외**: `계산 제외` 규칙은 `계산 제외(사용자 지정)`으로 표시하고 합계에 포함하지 않습니다.
5. **근무시간 계산**: 인정출근은 실제 출근과 08:00 중 늦은 시각입니다. 퇴근이 출근보다 이르면 익일 퇴근으로 계산합니다. 인정근무는 `max(퇴근 - 인정출근, 0)`입니다. 퇴근이 14:00보다 늦으면 1시간을 차감하고, `업무 중 휴게`는 신청 시작·종료가 모두 있을 때 신청 시간을 추가 차감합니다. 신청 시각이 없으면 추가 차감은 0입니다. 엑셀 `제외시간 > 외출`에 기록된 시간도 추가 차감합니다. 반차·생일휴가·단축·건강검진은 4시간을 가산하며, 최종시간은 `인정근무 - 휴게차감 - 외출시간 + 반차가산`입니다.
6. **월간 요약**: 근무일수는 실근무일과 연차일의 합입니다. 기준시간은 `근무일수 × 8시간`, 부족/초과는 `실 근무시간 합계 - 기준 근무시간`입니다.
7. **오늘 퇴근 목표**: `필요시간 = (근무일수 + 1) × 8시간 - 현재 합계`입니다. 4시간 가산을 선택하면 필요시간에서 4시간을 빼고, 인정출근 시각에 더합니다. 퇴근 목표가 14:00보다 늦으면 휴게 1시간을 더합니다. 필요한 실근무가 0 이하이면 이미 기준을 충족한 것으로 표시합니다. 반차일에는 `14:00 이전에 퇴근하면 휴게 1시간이 차감되지 않습니다.` 안내를 표시합니다.

근태 규칙은 앱 설정 폴더의 `item-rules.json`에, 그룹웨어 로그인 세션은 같은 폴더의 `groupware.json`(본인만 읽기 가능)에 저장됩니다. 비밀번호는 저장하지 않으며, 세션이 만료되면 로그인 창이 다시 열립니다. 개인 출결 엑셀 파일은 저장소에 포함하지 않습니다.

## 첫 실행 안내

- **macOS (서명 없음)**: 앱을 우클릭해 `열기`를 선택하거나, 시스템 설정 → 개인정보 보호 및 보안 → `그래도 열기`를 선택합니다. 또는 터미널에서 실행합니다.
  ```sh
  xattr -dr com.apple.quarantine "/Applications/Amaranth Attendance.app"
  ```
- **Windows**: SmartScreen에서 `추가 정보` → `실행`을 선택합니다.

## 개발

```sh
npm install
npm run tauri dev
cd src-tauri && cargo test
```

## 릴리스

`src-tauri/tauri.conf.json`의 버전을 올린 뒤 태그를 푸시합니다.

```sh
git tag vX.Y.Z
git push origin vX.Y.Z
```

GitHub Actions가 Windows 설치 파일과 macOS universal `.dmg`를 Releases에 게시합니다. 앱은 서명되지 않습니다.
